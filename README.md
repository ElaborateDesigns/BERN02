# BERN02: Hierarchical Models and Testing

## Description
Course exercise "Hierarchical models and Testing" for BERN02,
autumn semester 2026, Lund University.

Repo author: Roland Hansson

## Data
The data file `towelData.csv`, also available on
[OSF](https://osf.io/ycx49/), originates with the paper:

Scheibehenne, B. (University of Geneva), Jamil, T. (University of
Amsterdam), & Wagenmakers, E.-J. (University of Amsterdam) (2016).
*Bayesian Evidence Synthesis Can Reconcile Seemingly Inconsistent
Results: The Case of Hotel Towel Reuse.* Psychological Science,
27(7), 1043–1046.
DOI: [10.1177/0956797616644081](https://doi.org/10.1177/0956797616644081)
